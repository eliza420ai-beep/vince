# Standup Data Fetcher — How Agents Generate Daily Insights

## Overview

Each agent section in daily insights is generated by a function in:
```
src/plugins/plugin-inter-agent/src/standup/standupDataFetcher.ts
```

The functions are called during standup and their outputs concatenated into `docs/standup/daily-insights/YYYY-MM-DD-shared-insights.md`.

## The Pattern

```typescript
// Each fetcher follows this pattern:
export async function fetchAgentData(runtime: IAgentRuntime): Promise<string> {
  // 1. Get data from services/APIs
  // 2. Format into markdown
  // 3. Return string that gets inserted into daily insights
}
```

## How to Update the Format

### 1. Find the fetcher function
Look for `fetchEchoData()` around line 580.

### 2. Change the output format
Current (raw tweets):
```typescript
const tweetLines = allTweets.slice(0, 10).map((t) => {
  return `@${handle}: ${snippet} (${t.metrics?.likeCount ?? 0} likes)`;
});
let sentimentBlock = `**CT sentiment (${allTweets.length} posts):**\n${tweetLines.join("\n")}`;
```

New (structured table):
```typescript
// Extract structured signals from tweets
const assetSignals = extractSignalsFromTweets(allTweets);

// Build table
const tableRows = assetSignals.map(a => 
  `| ${a.asset} | ${a.sentiment} | ${a.narrative} | ${a.signal} |`
).join("\n");

let sentimentBlock = `## ECHO — Structured Sentiment

### Asset Sentiment
| Asset | CT Sentiment | Dominant Narrative | Signal |
|-------|--------------|-------------------|--------|
${tableRows}

### Contrarian Alert
${generateContrarianAlert(assetSignals)}

### Actionable Takeaway
${generateTakeaway(assetSignals)}
`;
```

## Key Insight

The agents don't "know" to use the new template — you need to update the **prompts in the fetcher functions**. The template files are documentation; the code is the enforcement mechanism.
